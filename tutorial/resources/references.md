## Papers

### Must-Read Papers

**Transformers**:
- "Attention Is All You Need" (2017) - Original transformer paper
  - https://arxiv.org/abs/1706.03762

**BERT**:
- "BERT: Pre-training of Deep Bidirectional Transformers" (2018)
  - https://arxiv.org/abs/1810.04805

**GPT Series**:
- GPT-2: "Language Models are Unsupervised Multitask Learners" (2019)
- GPT-3: "Language Models are Few-Shot Learners" (2020)
  - https://arxiv.org/abs/2005.14165

**Parameter-Efficient Fine-tuning**:
- "LoRA: Low-Rank Adaptation of Large Language Models" (2021)
  - https://arxiv.org/abs/2106.09685

### Survey Papers
- "Pre-trained Models for Natural Language Processing: A Survey" (2020)
  - https://arxiv.org/abs/2003.08271

## How to Use These Resources

### For This Tutorial

**Week 1**: Focus on PyTorch basics and Transformers docs
**Week 2**: Read Ray Train docs and distributed training guides
**Week 3**: Study FastAPI and Ray Serve tutorials
**Week 4**: Review Kubernetes and monitoring best practices
**Week 5**: Learn about authentication and security patterns
**Week 6**: Explore cloud platform docs

### For Deeper Learning

1. **Theory**: Read papers and textbooks
2. **Practice**: Follow tutorials and courses
3. **Community**: Join forums and discussions
4. **Build**: Create your own projects
5. **Share**: Write blogs, give talks, contribute

**Remember**: You don't need to read everything! Pick resources relevant to your current week and interests.
